# پرامپت و راهنمای UI/UX داشبورد فروشنده چاپلی

## پرامپت اجرایی

یک داشبورد فروشنده فارسی، RTL، mobile-first و بسیار چشم‌گیر برای نسل Z طراحی کن؛ حرفه‌ای اما نه خشک. زبان بصری از کارت‌های سفید با گوشه‌های نرم، زمینه‌ی یاسی بسیار روشن، مشکی جوهری، سبز لیمویی و بنفش الکتریکی ساخته شود. تراکم اطلاعات بالا باشد اما با فاصله‌گذاری، سلسله‌مراتب عددی و progressive disclosure خسته‌کننده نشود. نوار کناری در سمت راست نیمه‌جمع‌شونده باشد و در موبایل به drawer تبدیل شود. فونت IRANYekanX، اعداد فارسی، micro-copy کوتاه و خودمانی، انیمیشن‌های ظریف و دسترس‌پذیر، focus state واضح و حداقل ارتفاع لمس 44px الزامی است.

## معماری و هک‌های UX

- **پوسته:** sidebar ثابت راست، header چسبان، command/search در دسترس و CTA اصلی متناسب با صفحه. حالت جمع‌شده فقط آیکن و tooltip دارد.
- **مالی:** KPIها با «عدد، معنی و تغییر» نمایش داده می‌شوند. درآمد و سود جدا هستند تا برداشت اشتباه نشود. مبلغ قابل برداشت تنها منبع درخواست تسویه است. فیلترها روی همه‌ی نمودارها اثر دارند و خروجی CSV دقیقاً همان فیلتر را منعکس می‌کند.
- **حساب‌ها:** کارت‌های بانکی به‌صورت لیست قابل‌مرتب‌سازی هستند؛ اولین کارت همیشه «حساب اصلی» است. drag handle، جایگاه مقصد و fallback دکمه‌ای برای دسترس‌پذیری وجود دارد. فرم افزودن/ویرایش در پنل متمرکز باز می‌شود.
- **فروشگاه:** آمار هفتگی، ماهانه و کل با rank delta دیده می‌شود. فیلدهای هویتی و ارتباطی editable هستند؛ ایمیل مالک readonly و دلیل آن توضیح داده می‌شود. preview کوچک هویت فروشگاه در کنار فرم، نتیجه‌ی تغییرات را زنده نشان می‌دهد.
- **محصولات:** status tabs با شمارنده، جست‌وجو و اکشن‌های درجا. ساخت محصول یک wizard مرحله‌ای با autosave است: دسته‌بندی ← طراحی ← موکاپ ← اطلاعات ← قیمت و تنوع ← جزئیات ← بازبینی. خروج در هر مرحله پیش‌نویس را حفظ می‌کند.
- **آموزش:** کارت‌های کوچک با thumbnail، مدت، فایل و checkbox تکمیل. نوار پیشرفت و جمله‌ی متناسب با درصد، حس پیشروی می‌دهد بدون آن‌که کودکانه باشد.
- **موبایل:** جدول‌ها به کارت تبدیل می‌شوند، نمودارها scroll نمی‌خورند، CTA مهم sticky است و sidebar از راست با backdrop باز می‌شود.

## قواعد متن

عنوان‌ها رسمی و دقیق؛ توضیح‌ها کوتاه و صمیمی. به‌جای «خطا رخ داد» اقدام بعدی گفته شود. درآمد با ریال و معادل خوانا، نرخ‌ها با مقایسه‌ی دوره‌ی قبل، و وضعیت تأیید با علت و مسیر اصلاح نمایش داده شود.
